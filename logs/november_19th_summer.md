# November 19, 2026 — Summer

**Status:** Repository commits and crate publication are recorded in Git history. The human-data run outputs described here remain on HPC scratch; this log is local and has not been committed or pushed.

I fixed and polished the Rust release, including the Cleaver integration and clearer terminal output, then prepared and published Splice Girl crate releases. Git history records crates.io publications for versions 0.1.0, 0.2.0, and 0.2.1. For the 0.2.0 release, I changed the project license to Creative Commons Attribution 4.0 and added a citation request. I also updated the junction converter so its QC reports the assignment denominator and percentages, and separates ambiguous assignments within one gene from assignments spanning genes; this reporting change did not change which junctions were counted. The 0.2.1 release recorded that converter update.

On the HPC, I downloaded case sample SRR36710386. Its first FASTQ conversion attempt failed because the SRA file was nested one directory deeper than the command expected. I corrected the input path and reran conversion as Slurm job 27843675; it completed successfully in 2 minutes 39 seconds and produced paired FASTQ files of about 18 GB each (about 36 GB total). A module conflict involving HDF5 also interrupted the first attempt to load the alignment tools; unloading the SRA-Tools module resolved it.

I generated the shared-splice-site reference map from 5,087,789 annotated exons across 646,577 transcripts. It contained 711,654 junction annotation rows and 536,254 graph nodes; 40 junction rows mapped to the same node, and no overlapping exon pairs were skipped. I then ran SRR36710386 through alignment and junction extraction with this reference. Slurm job 27844959 completed successfully in 1 hour 41 minutes 47 seconds. HISAT2 reported a 97.54% overall alignment rate across 54,679,380 paired reads. Junction QC recorded 118,356,885 SAM records, 28,844,691 assigned junction observations, 1,274,883 ambiguous observations, and 210,520 written junction rows. The 28.8 million figure is an observation count from the junction-assignment stage, not a claim that the whole analysis ran in five seconds.

I ran the Rust Hodge analysis on the resulting junction table as Slurm job 27866517; it completed in 5 seconds and wrote `sample_metrics.tsv` (3.8 MB) and `junction_components.tsv` (34 MB). For ENSG00000000003.18, the graph had 10 nodes and 12 edges, with 2,237 total support; the cycle fraction was 0.4670, and the reconstruction, kernel, and orthogonality checks passed. I also generated an SVG for that gene. These are results for one case sample and validate a working run, not a case-control finding or evidence of disease causation.
