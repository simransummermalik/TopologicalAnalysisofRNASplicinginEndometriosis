you ran it. what now?

Read the answer, not just “PASS”.

Open target/website-demo-report/report.html, the file you made in the last demo step. The report brings the figures, measurements and exclusions together.

What to look at first

  1. Gene summary: both synthetic genes should have two eligible cases and two eligible controls. Their differences should be about +0.5556 and −0.5556.
  2. Individual samples: inspect the points and exact values. A group average does not tell you whether its samples agree.
  3. Excluded samples: control_03 has no junction data and must remain excluded, not assigned a zero.
  4. View decomposition: open a sample’s generated graph to see the observed, gradient and cycle signals together.

What does the cycle fraction mean?

It measures how much squared edge signal lies in cycle space after removing the gradient projection. Zero means the observed signal has no cycle-space part; one means all its signal is in that space. Our equal-weight exon-skipping fixture gives one ninth.

checks: PASS means the numerical identities passed. It does not mean a gene is disease-associated, the samples are biologically comparable, or circular RNA was detected.

Which file is which?

File in the report folderWhat you can find there
report.htmlThe readable report. Open this first.
sample_metrics.tsvEach sample/gene’s graph size, support, cycle fraction and math checks.
junction_components.tsvEach junction’s count, normalized signal, gradient and cycle component.

gene_summaries.tsvGroup summaries and the case-minus-control difference for each gene.

A TSV can be opened as text or in a spreadsheet. Choose tabs as the column separator if asked. Keep all report files together so its relative links keep working.

Where are the p-values?

The basic compare and report commands are descriptive. The separate stats command requires a gene list and explicit testing settings. It adds raw and BH-adjusted p-values, a gene-set test, and other tables.

In the two-gene statistical demo, both raw and adjusted p-values are one third. That example checks the calculation; large-looking toy effects do not automatically give strong statistical evidence.

See the complete statistics and preprocessing commands after the basic demo. Real data need reviewed QC, eligibility and design rules before those tests are interpreted.

If something goes wrong

“cargo: command not found”

Rust/Cargo is missing or unavailable in this terminal. Follow the Rust setup link in step 1, reopen the terminal and check the versions again.

“splice-girl: command not found”

The installed executable may not be on PATH. You can run the demo with cargo run -- from the project folder instead. Installing the shorter command is optional.

It cannot find the input file

Run pwd and ls Cargo.toml README.md. You should be in the project root. The demo paths are relative to that folder. Check spelling and do not paste the terminal’s prompt as part of a command.

“already exists”

The output is protected. Choose a new filename or folder, such as target/website-demo-report-2. You do not need to delete an old result to try again.

Validation failed when I added the demo manifest

That is an intentional mismatch example: orphan_01 has no metadata and control_03 has no junction data. The first validation command in step 4 should pass; the example with the manifest should report failure.

I clicked Copy but it says the text is selected

Your browser did not allow clipboard access. Press Command+C on macOS or Ctrl+C on other systems, then paste into your terminal. Copying never runs a command automatically.
