Glossary

You don’t have to learn every term before trying the demo. Come back when a word gets in the way.

The biology

RNA splicing
Removing introns and joining selected exons from an early RNA molecule.
Exon / intron
Exons are sections that can remain in finished RNA. Introns are intervening sections usually removed during splicing.
Read
A short sequence reported by an RNA-sequencing experiment. A read crossing an exon join can support a splice junction.
Splice junction
A connection between exons, supported by sequencing evidence. It becomes an edge in the graph.
Case / control
In the real study, a case has endometriosis; a control is from the comparison group. The demo uses made-up samples and labels, not patient measurements.
Eutopic endometrium
The uterine lining in its usual location. This is the tissue selected for both groups in the planned comparison.

The graph and math

Node / edge
A node is a graph point; an edge connects two points. Here, annotated exons are nodes and splice junctions are edges.
Read support / count
The number of eligible read alignments supporting a junction. It is not a count of subjects or necessarily independent RNA molecules.
Normalization
Dividing each junction count by the total support in that sample/gene. The weights then describe relative usage.
Gradient component
The part of an edge signal explained by differences between values assigned to nodes.
Cycle-space component
The remaining signal after the gradient projection. Graph loops and alternative paths can support this component.
Cycle fraction
The squared size of the cycle-space component divided by the squared size of the original signal. It is not a circular-RNA percentage or a diagnosis.
Effect size
A numerical group difference. Here, the basic effect is mean case cycle fraction minus mean control cycle fraction.
P-value
A measure of how unusual the observed statistic is under the test’s null assumptions. It is not the probability that a gene causes disease. The basic report does not calculate it.

The files and terminal

Terminal / CLI
The terminal is where you type commands. A command-line interface, or CLI, is a program used that way.
Rust / Cargo
Rust is the language used for the graph tool. Cargo builds and runs Rust projects.
Project root
The main repository folder containing Cargo.toml and README.md. Run the demo commands here.
TSV / manifest
A TSV is a table separated by tabs. A sample manifest lists sample IDs and group labels. A run manifest records the files and settings used for an analysis; they have different jobs.
FASTQ / SAM / BAM
FASTQ stores sequence reads and quality scores. SAM stores alignments as text; BAM is a binary alignment format. Preprocessing turns this evidence into junction counts.
SVG / HTML
SVG is the graph image format. HTML is the report format. Both can be opened in a browser; the saved report works offline.
Exit status
A command’s result code. Zero usually means success; a nonzero code means a reported problem. The demo includes an explicitly labeled intentional validation failure.
