# Splice Girl website

A small, buildless About page for Splice Girl. It uses plain HTML and CSS with
no framework, JavaScript, external fonts, or other dependencies. The full page
fits inside one screen without a long scroll.

## Preview locally

From the repository root:

```sh
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/website/
```

## Files

- `index.html` contains the About page and an embedded copy of the complete
  `assets/splice_girl_banner.txt` artwork.
- `styles.css` contains the simple presentation-inspired Y2K layout.

The website is local only. Nothing in this folder deploys or publishes it.
