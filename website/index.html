Splice Girl

Graph and Hodge analysis for RNA splice-junction data.

Splice Girl is a Rust command-line tool for building splice graphs, separating their gradient and cycle-space signals, and comparing sample-level measurements. It takes standardized junction counts and saves tables, graph figures and an offline report.

Quickstart · How the analysis works · Output reference

Build from source

Requires Rust 1.85 or newer. Download or clone the source repository, then run this from the folder containing Cargo.toml:

Terminal 
cargo install --path .
splice-girl --help

New to Rust or the terminal? The setup guide explains each step. You can also run the examples from source with cargo run --, without installing a global command.

Run an example

The repository includes synthetic inputs with known mathematical answers. This example analyzes a three-exon graph with an exon-skipping path:

Terminal 
cargo run -- analyze tests/fixtures/exon_skip.tsv

Expected cycle fraction: 0.1111111111, with checks: PASS. Continue through the seven-step quickstart to compare samples, generate a graph and save a report.

Input and output

StageFormat
Junction inputA tab-separated table with sample_id, gene_id, from, to and count.
Sample metadataA manifest providing the sample IDs and case/control labels for comparisons.
ResultsPer-sample measurements, signed junction components, comparison tables, SVG graphs and an HTML report.

Sequencing reads are prepared separately with the Cleaver/HISAT2 adapter. The graph tool reads junction tables, not raw FASTQ files. See the output reference for file-by-file explanations.

Research status

The software and synthetic workflows are working. A bounded CDH11 technical pilot from one million cleaned read pairs of one control sample has independent count and mathematical checks. The complete eight-sample endometriosis/control analysis remains in progress.

Demo results are synthetic. A cycle-space signal does not by itself establish circular RNA, a disease association or causation.
